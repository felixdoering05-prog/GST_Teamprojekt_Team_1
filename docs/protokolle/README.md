# Sitzungsprotokolle

[← Startseite](../../README.md)

Hier werden tatsächliche Teamtermine nachvollziehbar dokumentiert. Entwicklungsprotokolle und technische Arbeitsnachweise unten sind keine Teamtermine. Fehlende Termine und Beschlüsse dürfen nur anhand tatsächlicher Aufzeichnungen nachgetragen werden.

## Neues Protokoll erstellen

1. [Vorlage](VORLAGE.md) öffnen und den Markdown-Inhalt kopieren.
2. Im Ordner `docs/protokolle/` über **Add file → Create new file** eine Datei `JJJJ-MM-TT-teamtermin.md` anlegen; bei mehreren Terminen einen Zusatz verwenden.
3. Datum, Teilnehmende, Ergebnisse, Beschlüsse und konkrete Folgeaufgaben ausfüllen. Nicht besprochene Punkte als offen kennzeichnen.
4. Unter „Commit changes“ einen neuen Branch wählen und einen Pull Request erstellen. Eine teilnehmende Person liest gegen.
5. Nach dem Review Status und Freigabe im Protokoll ergänzen und den Eintrag unten verlinken. Folgeaufgaben als Issues anlegen.

Korrekturen nach Freigabe als datierten Nachtrag festhalten. Wichtige Beschlüsse zusätzlich im [Entscheidungsprotokoll](../entscheidungen.md) verlinken. Keine privaten Kontaktdaten eintragen: Das Repository ist öffentlich.
