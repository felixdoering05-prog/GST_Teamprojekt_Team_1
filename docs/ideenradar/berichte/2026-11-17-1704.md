## Home Assistant und Gebäude-KI

**Keine neue Empfehlung.** Für die REST-Anbindung dokumentiert Home Assistant den Abruf von Zuständen und den Aufruf von Diensten. Im D21-Adapter auf main 7bee25b sind Kontozuordnung, eine begrenzte Lampenliste und die Unterscheidung von on, off, unknown und unavailable bereits vorhanden. Die Zustandsabfrage liefert bei fehlender Verfügbarkeit einen leeren Schaltwert. Damit ist das in RADAR-003 betrachtete Grundmuster im Lampenadapter bereits umgesetzt. Der heutige Abgleich liefert keinen Anlass für einen zusätzlichen Adapter. [Home Assistant REST API](https://developers.home-assistant.io/docs/api/rest/) · [D21-Adapter](https://github.com/felixdoering05-prog/GST_Teamprojekt_Team_1/blob/7bee25b/dashboard/backend/src/home-assistant.js)

Der Hauptstand enthält die Zusammenführung von PR #219 zur einheitlichen Lampenbedienung. Beim Abruf waren keine Pull Requests offen. Der Backlog und die bisherigen Berichte wurden auf Überschneidungen abgeglichen. Diese Sichtung bestätigt die im Code vorhandenen Prüfungen. Das Verhalten realer Lampen und die vollständige Verbindung vom KI-Werkzeug zum Gerät wurden in diesem Lauf nicht erprobt.
