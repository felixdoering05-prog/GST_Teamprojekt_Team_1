# Beispieldaten

Hier liegen kleine, freigegebene Eingaben für nachvollziehbare Tests. Noch keine Daten vorhanden.

Zu jeder Datei dokumentieren:

- Quelle und Nutzungsfreigabe
- Inhalt, Spalten und Einheiten
- Erstellungsdatum und Bezug zum Modellstand
- Bekannte Einschränkungen

Synthetische Beispiele ausdrücklich kennzeichnen. Keine Zugangsdaten, personenbezogenen Angaben oder vertraulichen Projektdaten ablegen.
